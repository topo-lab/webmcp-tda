# Devpost image captions

## Thumbnail

WebMCP TDA: browser-local persistent homology for a shared human-agent workspace.

## 01 Point-cloud workbench

The human workbench accepts 2D and 3D coordinates. People can drag points, enter exact values, choose a complex, and inspect the same input an agent submitted.

## 02 Persistence result

A synchronized result view connects feature counts and the persistence diagram to the filtration controls and geometric preview.

## 03 Image pipeline

The image workflow keeps the original photograph, grayscale conversion, and binary mask visible instead of hiding preprocessing inside the computation.

## 04 Image result

Cubical persistence runs locally in WebAssembly and returns feature counts, essential classes, H1 loops, and a dynamically fitted persistence diagram.

## 05 WebMCP tools

Four typed tools let an agent inspect capabilities, compute point-cloud or image persistence, and read the result currently shared with the person.
